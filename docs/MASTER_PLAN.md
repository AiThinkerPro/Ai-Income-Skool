## 1. Positioning: why someone pays for this

Most "make money with AI" communities sell motivation and screenshots. We'll sell **proof and execution**:

| Them | Us |
|---|---|
| "10 AI side hustles" listicles | Each course ends with a **shipped asset** (live gig, listed product, signed client) |
| Generic ChatGPT prompts | **Claude-specific workflows**: Projects, Artifacts, Claude Code, Skills, MCP connectors, agents |
| Income screenshots | **Public build logs**: we run every course ourselves and show real numbers, the good and the bad |
| Content dump | **Weekly cadence + accountability**: challenges, wins channel, live calls |

**Who it's for:** beginners and side-hustlers (25–55, employed, 5–10 hrs/week), freelancers who want AI leverage, and non-technical people curious about Claude Code.
**Who it's not for:** people looking for get-rich-quick. We say so openly, which builds trust and cuts down refunds.

**Compliance rule (non-negotiable):** no guaranteed-income claims. Every course has an earnings disclaimer, and every "result" shown is real and labeled typical or atypical. Paid communities live or die on trust, and the FTC enforces this.

## 5. Lesson format standard (every lesson)

Each lesson folder: `courses/<course-id>/<NN-lesson-slug>/`

| File | Purpose |
|---|---|
| `lesson.md` | Text version: Goal → Why it matters → Steps (numbered, screenshots) → Copy-paste prompts → Common mistakes → Action item → Proof-of-work post |
| `script.md` | Video script (hook 0–10s, problem, demo, recap, CTA to post in community) |
| `video/` | Motion-graphic explainer (Remotion) and/or Google Flow b-roll prompts + outputs |
| `assets/` | Templates, prompt files, checklists |

**Video rules:** 3–8 min per lesson. Use motion graphics (Remotion) for concepts and frameworks, **screen recordings** for hands-on demos (they build trust; never replace them with AI video), and Google Flow for cinematic b-roll, intros and story scenes only.
**Brand kit:** one color palette, fonts, intro/outro sting, lower-thirds. Built once as Remotion components and reused everywhere.

## 6. Content production pipeline (Claude sessions)

```
Outline (course spec) → Lesson text → Video script → Remotion scenes / Flow prompts → Render → QA → Upload to Skool
```

1. **Course spec**: learner outcome, prerequisites, lesson list, deliverable, real-world proof plan.
2. **Text lessons**: written by Claude, edited by you for voice and accuracy. **You test every step yourself.**
3. **Scripts**: derived from the text, punchier.
4. **Visuals**: Remotion compositions from a shared template library; Flow prompts generated in a `flow-prompts.md` for you to run in Google Flow.
5. **Voiceover**: your voice (best for trust) or a consistent AI voice. Pick one and keep it.
6. **QA checklist**: accuracy, current UI screenshots, disclaimer present, links work.

Throughput target: **1 mini course per week** after the launch set.

## 8. Growth & launch plan

**Pre-launch (weeks 1–4)**
- Build the free Starter Kit + waitlist landing page.
- Daily short-form content (TikTok/Shorts/Reels/LinkedIn/X) produced with our own pipeline. **The marketing is itself proof that the course works.**
- Run the C1 course publicly as a build log on your own channel.
- Goal: 1,000 waitlist / free-group members.

**Launch (week 5)**
- 5-day launch: free live workshop "Make your first $100 with Claude this week" → founding-member offer (100 seats @ $29 for life) → close cart.
- Target: 5–10% waitlist conversion = 50–100 founding members.

**Post-launch (months 2–6)**
- Affiliate program (Skool supports affiliates): 30–40% recurring commission for members.
- Weekly YouTube long-form + daily Shorts; collaborations with AI/side-hustle creators.
- Member case studies → testimonials page.
- Month 4: open VIP tier.

**KPIs to track weekly:** free→paid conversion, MRR, churn, % members posting a win within 30 days, lesson completion rate.
